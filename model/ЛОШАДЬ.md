# Лошадь

Вьючное животное: покупается в городе, ходит за героем, слушается, возит вещи,
растёт в бою и смертно.

## На чём стоит

Всё нужное у игры уже есть — достраивать почти нечего.

| что нужно | чем закрывается | где |
|---|---|---|
| слот персонажа | `HumaniodUnit.warpet` — один на героя | 54544 |
| привязка | `AddWarpet(pet)` / `RemoveWarpet(pet)` | 55929, 55959 |
| переживает сохранение | `Data.warpetID`, `SaveLoadManager.warpets` | 78931, 126372 |
| следование | `summonGroup.AddSummoned` | 55956 |
| команды | `commandsName.follow`, `standGuard`, `stop` | 76690 |
| груз | `UnitAttribute.items` — обычный `ItemStock` | 68836 |
| груз при смерти | у лошадей `canLootCorpse = True`, груз лежит в `items` | units.tsv |
| рождение | `AreaManager.CreateCharacter(имя, поза, поворот, сторона)` | 79592 |
| правое меню | `RightClickMenuManager.ShowRightClickMenu` | 159309 |
| окно цены | `CostDialog.Show(заголовок, текст, цена, кошелёк, ответ)` | 114879 |
| кошелёк | `ManagementModeCore.wealth`, тратится `TakeMoney(-цена)` | 115081 |
| ячейка в панели | `SummonedSlot` — призванные её получают | 159390 |

Игра сама раздаёт питомцев так же: у существа есть `warPetPrefabs`, и при рождении
оттуда берётся случайный. Бандиту — волк, герою — лошадь.

## Что пишем

Один новый файл, `ItemForge/Steed.cs`.

### 1. Покупка

Префикс на `ShowRightClickMenu`: дочитываем приватное поле `target` и дописываем
свои пункты в словарь, пока меню ещё не собрано.

Пункт «Купить» показываем, когда цель — лошадь (раса `animal`, имя из списка
`Breeds`), жива, ничья (`isWarpet` не стоит), и у текущего героя питомца нет.

По нажатию — `CostDialog.Show`, он сам покажет цену красным, если денег мало.
По согласию:

    ManagementModeCore.TakeMoney(-Price);
    var horse = AreaManager.Instance.CreateCharacter(Model, поза, поворот, Faction.player);
    старую лошадь убрать;
    герой.AddWarpet(horse);
    horse.Data.canKill = true;        // игра ставит false, нам нужна смертная

Новую лошадь **рождаем**, а не перекрашиваем старую: вьючные модели
(`CargoHorse_Equipment`, `_Foods`, `_Material`) уже есть в игре, с вьюками на боках.
Это и есть та «замена модели» — только не подменой меша на живом объекте, а тем же
путём, которым игра делает своих питомцев.

### 2. Команды

Три пункта в том же меню, когда цель — своя лошадь:

- «Следовать» — `HandleCommand(follow, хозяин)`
- «Стоять» — `HandleCommand(standGuard)`
- «Отпустить» — `RemoveWarpet`, она возвращается в дикие

### 3. Груз

Предел веса — свой: у `HumaniodUnit` есть `CountCurrentWeight`, у зверя нет.

    предел = Base + Carry * сила

Сила у зверей уже есть — её раздаёт `Beastly` по размеру. `ItemStock.SumWeight` мы
уже правим в `Temper`, лошадь встаёт туда же ещё одной сумкой отряда.

### 4. Опыт

Опыт боя — только за свой нанесённый урон: подписка на `onUnitHurtOther`, а не
на общий котёл отряда. Тащилась рядом — не в счёт.

Опыт статов от перегруза — по той же тропе, что у людей в `Practice`: несла сверх
предела, значит сила растёт.

### 5. Смерть

`canKill = true` сразу после привязки. Груз уже лежит в `items`, а у лошадей
`canLootCorpse = True` — обыск покажет всё. При смерти снимаем `warpet`, чтобы
слот освободился под новую.

## Конфиг

Раздел `Steed`: `Enabled`, `Price` (30000 — монета это 10 000, значит три золотых),
`Breeds` (кого можно купить), `Model` (какую вьючную рождать), `Base` и `Carry`
(предел веса), `OwnDamageOnly`, `StrainExp`.

## Чего не будет

Строки в ряду отряда. `partyMembers` — это `List<HumaniodUnit>`, а `RegPartyMember`
лезет в `equipmentmanger`, `heroCareer` и боевую формацию, которых у лошади нет.
Ячейку в панели призванных она получит, ряд отряда — нет. Это цена пути А.
