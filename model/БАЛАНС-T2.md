# Баланс урона на второй ступени

Считано по живым числам: предметы из выгрузки игры, правила из `aor.itemforge.cfg`,
формулы из `Breach`, `Sinew`, `Hone`, `Anatomy`.

## Как считается удар сейчас

    пробитие = урон удара x собранность оружия (Focus)
    стена    = доспех (класс x ступень x место) + мясо и кость бойца
    порог    = 0,75 и 1,25 от стены

Ниже трёх четвертей стены не проходит ничего. Выше четверти сверх — проходит всё.
Между ними — по прямой. Мимо порога идут только двое: доля дробящего (`Through`)
и крит, который считается найденной щелью и проносит 30-50 % сквозь что угодно.

Мясо и кость: 0,4 за очко силы и 0,3 за очко выносливости — только на грудь.
На руки и ноги вдвое меньше.
