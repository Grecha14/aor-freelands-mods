# Моды для Age of Reforging: The Freelands

Три мода на BepInEx 5 и русский перевод — одним пакетом. Работают для героя любой расы;
у демона сверху свои заклинания и своя механика.

| Мод | Версия | Что делает |
|---|---|---|
| **DemonLook** (Demon Race) | 0.22.0 | Раса демона и «живой мир»: хозяйство городов и деревень, торговцы и караваны, шайки и звери на дорогах, шахты и зачистки, сон и дома горожан, дети, кражи и память о них, стража и облавы, ночлег по усталости, школы магии, маги в таверне, книга «Сказание». |
| **ItemForge** (Item Forge) | 2.0.0 | Вещи и бой: броня и пробитие по частям тела, износ, редкость и приписки, травмы и лечение, зелья и обезболивающее, еда и порча, отрубание голов и конечностей, кровь и лужи, усталость и голод героя. Внутри — русский перевод (`LocalizationPatch`). |
| **EncounterScale** (Encounter Scale) | 1.2.0 | Сила встреч и противников по уровню героя. |

## Что нужно

1. **Игра** Age of Reforging: The Freelands (Steam).
2. **BepInEx 5.4.23** для Windows x64 — загрузчик модов.
   Скачать `BepInEx_win_x64_5.4.23.x.zip` со страницы
   <https://github.com/BepInEx/BepInEx/releases> (раздел 5.4.23, не BepInEx 6).

## Установка

1. Распакуйте BepInEx в папку игры — туда, где лежит `Age of Reforging The Freelands.exe`.
   Обычно это `C:\Program Files (x86)\Steam\steamapps\common\Age of Reforging The Freelands`.
2. Запустите игру один раз до главного меню и закройте: BepInEx создаст свои папки.
3. Скопируйте папку `release\BepInEx` из этого репозитория в папку игры и согласитесь
   на слияние папок. То же лежит одним архивом в разделе **Releases** справа.
4. Проверьте, что вышло так:

   ```
   BepInEx\plugins\DemonLook\DemonLook.dll
   BepInEx\plugins\ItemForge\ItemForge.dll
   BepInEx\plugins\ItemForge\LocalizationPatch\*.tsv
   BepInEx\plugins\EncounterScale\EncounterScale.dll
   ```

   Каждый мод — в своей папке. Если положить DLL прямо в `plugins`, ItemForge не найдёт
   перевод рядом с собой, и перевод молча не встанет.

Меняйте DLL только при **закрытой** игре: пока она запущена, файл занят.

## Настройки

При первом запуске появятся файлы в `BepInEx\config`:
`aor.demonlook.cfg`, `aor.itemforge.cfg`, `aor.encounterscale.cfg`. У каждой настройки
есть описание. Почти у каждого правила есть `Enabled = true` — его можно выключить
отдельно, не трогая остальные.

Свои данные моды хранят рядом, по имени сохранения: `BepInEx\config\aor.*.<имя>.txt`
(хозяйство, кражи, усталость отрядов и т. п.).

## Клавиши

Все меняются в настройках. Большая часть нужна для проверки и разработки.

| Клавиша | Мод | Что делает |
|---|---|---|
| F6 | DemonLook | в редакторе персонажа — наложить облик демона |
| F7 | DemonLook | сбросить ползунки облика к нейтральным (для сравнения) |
| F7 | ItemForge | записать в журнал, кого вокруг держит вес груза |
| F8 | DemonLook | записать облик персонажа на экране в журнал в виде настроек |
| F5 | DemonLook | разметка мест для сцен; Ctrl и Alt — другие списки, Shift — стереть |
| F9 | ItemForge | замерить длину всех моделей оружия (несколько секунд) |
| F10 | ItemForge | положить весь комплект Короля Ада в сумку выбранного |
| F11 | ItemForge | дать опыт отряду и его зверям (для проверки) |
| Левый Ctrl + клик | ItemForge | приказ прирученному зверю, а не отряду |
| Insert | ItemForge | выписать вещи и комплекты в журнал |
| Home | ItemForge | выписать в журнал устройство оружия в руке |

F7 занят двумя модами сразу; если мешает — смените одну из клавиш в настройках.

## Удаление

Удалите папки модов из `BepInEx\plugins`. Сохранения, сделанные с модами, без них могут
не загрузиться или потерять часть вещей: в них есть то, чего нет в самой игре (дети
горожан, комплект Короля Ада, книга «Сказание», свои заклинания демона). Держите копию
сохранений до установки.

## Чего в пакете нет

- У автора дополнительно стоят чужие моды — **AutoBattleButton**, **DoorwayFix**,
  **KK No Negative Traits**. Они не наши и в пакет не входят; моды из пакета от них не
  зависят.
- Разобранного кода игры здесь нет и не будет: это чужой закрытый код. Для разработки его
  можно разобрать у себя — см. ниже.

## Для разработки

Памятка для ИИ-помощника и для человека — [AGENTS.md](AGENTS.md): как устроены моды,
как собрать, где ловушки. Карта всех модулей — [docs/MODULES.md](docs/MODULES.md).

### Инструменты

| Что | Зачем | Где взять |
|---|---|---|
| .NET SDK 8 или новее | сборка модов (проверено на 10.0.401) | <https://dotnet.microsoft.com/download> |
| BepInEx 5.4.23 x64 | в папке игры: и для запуска, и для сборки (из него берутся BepInEx.dll и 0Harmony.dll) | <https://github.com/BepInEx/BepInEx/releases> |
| ilspycmd | разобрать код игры, чтобы искать по нему классы и методы | `dotnet tool install -g ilspycmd` (<https://github.com/icsharpcode/ILSpy>) |
| Git | забрать репозиторий и вести свои правки | <https://git-scm.com/download/win> |
| Python 3 | только для расчётов баланса в `model/` | <https://www.python.org/downloads/> |
| Claude Code (по желанию) | ИИ-помощник, сам читает `CLAUDE.md` и `AGENTS.md` | <https://claude.com/claude-code> |

### Сборка

```powershell
.\build.ps1                      # собрать все три мода, DLL лягут в release\
.\build.ps1 -Install             # и поставить в игру (игра должна быть закрыта)
.\build.ps1 -GameDir "D:\Games\Age of Reforging The Freelands"   # если игра в другом месте
```

Код игры для справки:

```powershell
.\tools\decompile.ps1            # разберёт Assembly-CSharp и firstpass в папку GameSrc\
```
