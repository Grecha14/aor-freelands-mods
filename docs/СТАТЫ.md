# Статы, доступные предметам

Игра не ограничивает модификаторы по слоту: любой из перечисленных работает на любой
вещи. Списки ниже — не «что можно», а «что осмысленно», плюс отметка, что проверено
по коду, а что взято по названию.

Потолки, проверенные по `ClampUnitAttribute`: физическая и магическая защита 75,
шанс блока 100, снижение всего урона 1.0, сокращение перезарядки 0.8, экономия
выносливости 0.8. Сопротивление каждому типу урона — 80. Остальное без потолка.

## Характеристики

| Модификатор | Что делает |
|---|---|
| `Strength` | сила. Проверено: +1 к грузоподъёмности за очко, множитель урона |
| `Endurance` | выносливость. Проверено: +5 HP (ровно столько же даёт уровень), +5 к запасу сил, +0,05 HP и +0,1 сил в секунду, +1 к стойкости за очко |
| `Agility` | ловкость. Проверено: +1% к скорости атаки, +0.5% к скорости бега за очко |
| `Precision` | точность. Проверено: идёт в меткость, защиту и шанс крита |
| `Intelligence` | интеллект. Проверено: +1% к сокращению перезарядки, +0.5 к уклонению |
| `Willpower` | воля. Проверено: +5 маны за очко, идёт в магическую защиту |

## Бой: урон

| Модификатор | Что делает |
|---|---|
| `Attack` | меткость |
| `Crit` | шанс критического удара |
| `CritMultiple` | множитель критического урона |
| `MeleeDamage` | урон в ближнем бою, долей |
| `RangeDamage` | урон дальним боем |
| `MagicDamage` | магический урон |
| `StaminaDamage` | урон по выносливости цели |
| `DamageIncrease` | весь наносимый урон, множителем |
| `WeaponForce` | **сила толчка**, не урон. Проверено: отбрасывает цель, давит сквозь блок |
| `BlockBreak` | пробивание блока |
| `AttackSpeed` | скорость анимации удара. Проверено: `анимация = 0.5 + скорость` |
| `AttackRange` | дальность удара |
| `AttackAngle` | ширина зоны удара |

## Бой: защита

| Модификатор | Что делает |
|---|---|
| `Defence` | защита |
| `Dodge` | уклонение |
| `PDR` | **стойкость**, а не защита: урон она не режет вовсе. Порог сбоя действия `0,1 + PDR × 0,005` от макс. HP — удар дороже него ломает замах и каст; физические дебафы короче на PDR %, бафы длиннее на столько же. Потолок 75, и очко выносливости даёт +1 |
| `MDR` | магическая защита. Потолок 75 |
| `DamageReduce` | **снижение всего получаемого урона**. Проверено: множитель поверх сопротивлений, пробиванию не поддаётся |
| `Threat` | угроза, притягивает внимание врагов |
| `BlockAngle` | угол блока |
| `BlockEPsave` | экономия выносливости при блоке |

## Ресурсы

| Модификатор | Что делает |
|---|---|
| `HP` / `EP` / `MP` | запас здоровья, выносливости, маны |
| `HPPercent` | здоровье долей от максимума |
| `HPrestore` / `EPrestore` / `MPrestore` | восстановление в секунду |
| `EPsave` | экономия выносливости. Потолок 0.8 |
| `CooldownReduce` | сокращение перезарядки. Потолок 0.8 |
| `HealMD` | сила лечения |
| `MoveSpeed` | скорость передвижения |
| `TimeSpeed` | скорость течения времени для персонажа |

## Сопротивления и пробивание

Девять типов урона: `Sharp` режущий, `Blunt` тупой, `Stab` колющий, `Flame` огонь,
`Cold` холод, `Electric` электричество, `Poison` яд, `Positive` свет, `Negative` тьма.

| Семейство | Что делает |
|---|---|
| `<Тип>DamageResistance` | сопротивление этому типу. Потолок 80 |
| `<Тип>ResistancePenetration` | пробивание чужого сопротивления этого типа |
| `<Тип>SpellDamageModifier` | урон заклинаний этого типа |

Для демона важны `NegativeSpellDamageModifier` (тьма) и `NegativeResistancePenetration`.

## Урон по расам

`HumanDamageModifier`, `ElfDamageModifier`, `DwarfDamageModifier`, `BrutemanDamageModifier`,
`LizardDamageModifier`, `FairyDamageModifier`, `DemonDamageModifier`, `UndeadDamageModifier`,
`OrcDamageModifier`, `MythologicalDamageModifier`, `AnimalDamageModifier`, `InsectDamageModifier`.

Прибавка к урону по конкретной расе. Работает и против вас: `DemonDamageModifier` на
чужом снаряжении усилит удары по вашему демону.

## Призывы

`SummonDamageBonus`, `SummonHealthBonus` — урон и здоровье призванных существ.

## Мирные навыки

`Persuade` убеждение, `Bargain` торговля, `Intimidate` запугивание, `Pathfind` поиск пути,
`Insight` понимание, `Sneak` скрытность, `Mechanics` механика, `Theft` кража,
`Scholarly` наука, `Smithing` кузнечное дело, `Alchemy` алхимия, `Cooking` готовка,
`Traning` тренировка, `Medical` медицина, `Torture` пытки.

## Что к чему подходит

Смысловые рекомендации, не ограничения.

**Шлем** — восприятие, точность, сопротивления, устрашение, угроза.
**Доспех** — защита, снижение урона, сопротивления, угроза, здоровье.
**Поножи** — скорость передвижения, уклонение, выносливость и её экономия.
**Оружие** — урон, крит и его множитель, скорость и площадь удара, сила толчка, пробивание.
**Щит** — угол и экономия блока, снижение урона, защита, пробивание блока.
**Амулет** — магия, сопротивления, сила оружия, урон по расам.
**Пояс** — выносливость, её восстановление и экономия, снижение урона.
**Кольца** — крит, сокращение перезарядки, мирные навыки, урон по расам, пробивание.
